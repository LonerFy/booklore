# BookLore

Démo en ligne de BookLore, l'application de bibliothèque du département IRT (TP Laravel).

Cette version est un site statique pour GitHub Pages : les livres, auteurs, rayons et prêts sont des exemples,
et ce que vous ajoutez reste enregistré dans votre navigateur. L'application complète (PHP, base de données)
tourne avec Laravel, en local.

- Intro animée, catalogue avec filtres et tri, fiches de livres en 3D
- Prêts, retours avec tampon, retards au-delà de 14 jours
- Formulaires avec les mêmes règles de validation que l'application Laravel
- Photos de couvertures depuis Open Library, d'après l'ISBN

Animations : GSAP et Lenis, inclus dans `js/vendor`.
